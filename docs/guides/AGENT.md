# Guide de l'agent

Ce guide explique comment demander un congé, une permission ou un billet de sortie, et comment suivre ses demandes.

## Se connecter

1. Ouvrez l'adresse de l'application que vous ont donnée les RH, par exemple `https://rh.omit.local`.
2. Saisissez votre adresse email et le mot de passe provisoire reçu.
3. À la première connexion, choisissez un nouveau mot de passe : au moins 10 caractères, avec des lettres et des chiffres.

Après 30 minutes sans activité, vous êtes déconnecté. En cas d'oubli du mot de passe, adressez-vous à l'administrateur informatique.

## Voir mon solde de congés

Le **tableau de bord** affiche votre fiche et votre solde disponible. Le solde est calculé ainsi :

> disponible = jours acquis + reports − jours consommés − jours réservés pour des congés approuvés

« Historique » détaille chaque mouvement : acquisitions mensuelles, congés pris, corrections des RH.

## Faire une demande

1. Menu **Mes demandes**, puis **+ Congé**, **+ Permission** ou **+ Billet de sortie**.
2. Remplissez le formulaire. Pour un congé, le nombre de jours décomptés s'affiche tout seul, week-ends et jours fériés exclus si le type de congé le prévoit.
3. Cliquez sur **Enregistrer le brouillon**. Le brouillon n'est visible que de vous.
4. Ajoutez un justificatif si on vous le demande (PDF, JPG ou PNG, 5 Mo au maximum).
5. Cliquez sur **Envoyer aux RH**.

La demande reçoit alors une référence, par exemple `OMIT-CG-2026-00125`. Vous ne pouvez plus la modifier, sauf si les RH vous la renvoient pour correction.

L'envoi est refusé dans trois cas :

- votre solde est insuffisant, en comptant vos autres demandes en attente ;
- la période chevauche une autre de vos demandes ;
- un justificatif obligatoire manque.

## Suivre une demande

| Statut | Signification |
|---|---|
| Brouillon | En préparation, visible de vous seul |
| Soumise | Envoyée, en attente du contrôle des RH |
| À corriger | Les RH vous la renvoient : lisez leur commentaire, modifiez, renvoyez |
| Transmise au Médecin-Chef | Contrôle RH terminé, en attente de décision |
| Approuvée | Accordée ; pour un congé, les jours sont réservés sur votre solde |
| Finalisée | Enregistrée par les RH ; le document est prêt |
| Refusée | Le motif figure dans l'historique ; faites une nouvelle demande si besoin |
| Terminée | Période passée ; pour un congé, les jours sont définitivement décomptés |
| Annulée | Demande retirée |

Vous êtes prévenu à chaque étape importante : alerte **Notifications** en haut de l'écran, email, et SMS pour les décisions. Les emails et les SMS se règlent dans **Préférences de notification**.

## Annuler

- **Brouillon :** supprimez-le, ou annulez-le.
- **Demande soumise ou à corriger :** bouton **Annuler la demande**.
- **Demande approuvée :** seuls les RH peuvent l'annuler, avant le début du congé ; adressez-vous à eux. Les jours réservés vous sont alors rendus.

## Imprimer l'autorisation

Une fois la demande approuvée, ouvrez-la et cliquez sur **Télécharger l'autorisation (PDF)**, ou **Télécharger le billet (PDF)** pour une sortie.
